# Social cards

Rendered by `node scripts/og.mjs` from each figure's rest-pose snapshot and the site's Geist fonts, so the cards match the pages exactly. A generated-image version was tried first (Codex, 7 October 2026) and declined by the generator itself: it added background texture and altered the figure's geometry. Re-run the script after a figure or title changes, and bump the `-v1` suffix so caches refresh.
