# Prototype promoted to the whole site

The surveillance experiment is now the shared reading system for all six scenarios and ten comparisons. `/prototype/` redirects to `/` so old preview links remain useful.

See [the current design brief](REDESIGN.md), `ScrollComparison.astro`, `src/scripts/scenic-reading.js`, and `src/styles/layered-site.css`. Natural scroll reveals perspectives slowly through genuinely separate foreground, middle-distance and atmospheric layers. Two-way comparisons finish together in-place; three-way comparisons finish in unbounded reading below the scene. No text panels or nested scrolling.

Read together, motion pause, reduced motion, short screens, mobile and no JavaScript preserve direct access to all arguments. This remains local; publication needs explicit approval.
